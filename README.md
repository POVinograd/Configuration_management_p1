# Эмулятор UNIX-подобной командной оболочки

## Описание проекта

В рамках работы разработан эмулятор командной оболочки UNIX-подобной операционной системы. Эмулятор предоставляет интерактивный интерфейс для ввода команд и выполняет операции над виртуальной файловой системой, содержимое которой загружается из ZIP-архива.

Реализация выполнена поэтапно. Все пять этапов задания завершены: подготовлена интерактивная оболочка, добавлена конфигурация запуска, реализована работа с виртуальной файловой системой и поддержаны требуемые команды.

## Реализованные возможности

- интерактивный цикл ввода и выполнения команд (REPL);
- приглашение командной строки с именем пользователя и именем хоста;
- подстановка значений переменных окружения, в том числе переменных вида `$HOME`;
- завершение работы оболочки командой `exit`;
- передача параметров запуска для указания ZIP-архива виртуальной файловой системы и файла сценария;
- запуск команд из сценария при старте программы;
- вывод выполняемых команд и их результатов при обработке сценария;
- прекращение выполнения сценария при первой ошибке с выводом сообщения об ошибке;
- загрузка виртуальной файловой системы из ZIP-архива;
- работа с файловой системой в памяти без изменения исходного ZIP-архива;
- поддержка вложенных каталогов;
- обработка содержимого файлов, включая бинарные данные;
- реализация команд `ls`, `cd`, `uptime`, `echo`, `touch` и `cp`.

## Этапы выполнения

### Этап 1. Базовая командная оболочка

Реализован основной цикл работы оболочки: программа принимает пользовательские команды, разбирает ввод и передаёт его на выполнение. Добавлено приглашение командной строки с информацией о пользователе и хосте. Поддержана подстановка переменных окружения, а команда `exit` завершает работу приложения.

На этом этапе также подготовлены начальные обработчики команд `ls` и `cd`, которые в дальнейшем были связаны с виртуальной файловой системой.

### Этап 2. Параметры запуска и сценарии

Добавлена обработка аргументов командной строки. При запуске можно указать путь к архиву виртуальной файловой системы и файл сценария с последовательностью команд.

Если задан сценарий, его команды выполняются последовательно. В процессе выполнения отображаются команды и результаты их работы. При возникновении ошибки обработка сценария прекращается, а пользователь получает сообщение, описывающее ошибку.

Для проверки конфигурации запуска реализован вывод используемых параметров.

### Этап 3. Виртуальная файловая система

Реализована загрузка структуры файлов и каталогов из ZIP-архива. Файловая система представлена в памяти, поэтому операции изменения не модифицируют исходный архив.

Поддерживается обход каталогов, включая вложенные уровни. Содержимое файлов хранится так, чтобы можно было работать не только с текстовыми, но и с бинарными данными. При проверке учитываются архивы с различной структурой каталогов и вложенностью не менее трёх уровней.

### Этап 4. Основные команды оболочки

Реализованы команды для навигации по виртуальной файловой системе и вывода информации:

| Команда | Назначение |
|---|---|
| `ls` | Вывод содержимого текущего или указанного каталога |
| `cd` | Переход в другой каталог виртуальной файловой системы |
| `uptime` | Вывод информации о времени работы системы |
| `echo` | Вывод переданных аргументов с учётом подстановки переменных окружения |

Команды используют состояние оболочки и виртуальную файловую систему, а не выполняют операции с реальной файловой системой хоста.

### Этап 5. Операции с файлами

Реализованы команды `touch` и `cp`.

| Команда | Назначение |
|---|---|
| `touch` | Создание файла в виртуальной файловой системе |
| `cp` | Копирование файла в указанное место виртуальной файловой системы |

Изменения выполняются только во внутреннем представлении файловой системы в памяти. Исходный ZIP-архив остаётся неизменным.

## Примеры использования

После запуска оболочки можно выполнять команды:

```text
$ ls
$ cd documents
$ ls
$ echo Hello, world!
$ echo $HOME
$ touch notes.txt
$ cp notes.txt notes-copy.txt
$ uptime
$ exit
```

Для выполнения команд из сценария в файл записываются команды, по одной на строку. При запуске программы указываются параметры, соответствующие архиву виртуальной файловой системы и файлу сценария.

Пример содержимого сценария:

```text
ls
cd documents
ls
echo $HOME
```

## Работа с виртуальной файловой системой

Виртуальная файловая система загружается из ZIP-архива при запуске приложения. Команды оболочки обращаются к её внутреннему представлению. Создание файлов, копирование и переходы между каталогами выполняются в виртуальном пространстве.

Это позволяет проверять операции с файлами без изменения файлов хоста и исходного архива.

## Обработка ошибок

Оболочка обрабатывает некорректные команды и ошибки при работе с виртуальной файловой системой, выводя диагностические сообщения. При запуске сценария ошибка останавливает выполнение оставшихся команд сценария, чтобы последующие операции не выполнялись после неудачного шага.

## Проверка работы

При проверке реализации охвачены следующие сценарии:

- запуск оболочки и завершение командой `exit`;
- подстановка переменных окружения;
- вывод содержимого каталогов и переходы между ними;
- выполнение команд из файла сценария;
- остановка сценария при ошибке;
- загрузка виртуальной файловой системы из ZIP-архива;
- работа с вложенными каталогами;
- создание и копирование файлов;
- проверка того, что операции изменения не затрагивают исходный ZIP-архив;
- работа с архивами, содержащими файлы разных типов.

## Итог

Реализованы все пять этапов задания. Эмулятор поддерживает интерактивную работу и запуск сценариев, загружает виртуальную файловую систему из ZIP-архива и предоставляет набор требуемых команд для навигации и работы с файлами. Изменения файловой системы выполняются в памяти, без модификации исходного архива.
