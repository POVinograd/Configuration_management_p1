# Эмулятор UNIX shell

## Описание

Проект представляет собой эмулятор командной оболочки UNIX, реализованный на языке Python. Эмулятор максимально приближен по поведению к работе в командной строке UNIX-подобной ОС и поддерживает виртуальную файловую систему (VFS).

На текущем этапе реализованы первые три этапа задания:

- **Этап 1. REPL** — интерактивный режим работы с приглашением командной строки;
- **Этап 2. Конфигурация** — настройка параметров запуска через командную строку и стартовый скрипт;
- **Этап 3. VFS** — подключение виртуальной файловой системы на основе ZIP-архива.

## Этап 1. REPL

После запуска программа отображает приглашение командной строки, сформированное на основе реальных данных ОС, в которой исполняется эмулятор:

```
username@hostname:~$
```

Поддерживаются следующие команды:

- `ls` — заглушка команды просмотра содержимого каталога;
- `cd` — заглушка команды перехода в каталог;
- `exit` — завершение работы эмулятора.

### Особенности парсера

Парсер поддерживает раскрытие переменных окружения реальной ОС в форматах `$VARIABLE` и `${VARIABLE}`.

Пример:

```
username@hostname:~$ ls $HOME
ls: args = ['/home/user']
```

### Примеры работы

Команда `ls`:

```
username@hostname:~$ ls
ls: args = []
```

С аргументами:

```
username@hostname:~$ ls -l test
ls: args = ['-l', 'test']
```

Команда `cd`:

```
username@hostname:~$ cd test
cd: args = ['test']
```

Неизвестная команда:

```
username@hostname:~$ hello
Ошибка: неизвестная команда: hello
```

Некорректные кавычки:

```
username@hostname:~$ ls "test
Ошибка: некорректные кавычки в команде.
```

Выход:

```
username@hostname:~$ exit
```

## Этап 2. Конфигурация

Эмулятор поддерживает параметры командной строки для настройки запуска.

### Поддерживаемые параметры

- `--vfs <путь>` — путь к физическому расположению VFS;
- `--script <путь>` — путь к стартовому скрипту.

При запуске эмулятор выводит значения заданных параметров в отладочном режиме.

Пример:

```bash
py src\emulator.py --vfs C:\path\to\vfs.zip --script C:\path\to\script.txt
```

### Стартовый скрипт

Стартовый скрипт содержит команды эмулятора, которые выполняются последовательно после запуска программы. При выполнении скрипта на экране отображаются как введённые команды, так и их результаты, имитируя обычный диалог пользователя с эмулятором.

**Важно:** выполнение стартового скрипта **останавливается при первой ошибке**.

Пример скрипта:

```
ls
cd test
ls -l
```

Результат выполнения:

```
username@hostname:~$ ls
ls: args = []
username@hostname:~$ cd test
cd: args = ['test']
username@hostname:~$ ls -l
ls: args = ['-l']
```

### Обработка ошибок в скрипте

Если во время выполнения стартового скрипта встречается ошибочная команда, сообщение об ошибке выводится на экран, и выполнение скрипта **прекращается**.

Пример:

```
ls
unknown
cd test
```

Результат:

```
username@hostname:~$ ls
ls: args = []
username@hostname:~$ unknown
Ошибка: неизвестная команда: unknown
```

После завершения скрипта (успешного или из-за ошибки) эмулятор не прекращает работу — пользователь может продолжить вводить команды в интерактивном режиме.

## Этап 3. VFS

На этом этапе подключается виртуальная файловая система (VFS).

### Особенности реализации

- Все операции производятся **в памяти**. Запрещается распаковывать или иным образом модифицировать данные VFS на диске.
- Источником VFS является **ZIP-архив**. Для двоичных данных используется `base64` или аналогичный формат.
- Вложенные элементы VFS представляются через относительные пути внутри архива.
- При ошибке загрузки VFS (файл не найден, неверный формат) выводится сообщение об ошибке.

### Тестирование VFS

Создано несколько вариантов VFS-архивов для проверки работы:

- `minimal.zip` — минимальный VFS (один файл);
- `files.zip` — VFS с несколькими файлами;
- `deep.zip` — VFS с не менее чем 3 уровнями вложенности папок и файлов.

Примеры вызовов эмулятора для тестирования:

```bash
./run.sh --vfs vfs/minimal.zip --script scripts/test_vfs_minimal.sh
./run.sh --vfs vfs/files.zip --script scripts/test_vfs_files.sh
./run.sh --vfs vfs/deep.zip --script scripts/test_vfs_deep.sh
```

### Стартовый скрипт для тестирования всех команд

Создан универсальный стартовый скрипт `scripts/test_all.sh`, в котором собраны примеры всех режимов команд, реализованных на этапах 1–3, включая работу с VFS и обработку ошибок.

Пример запуска:

```bash
./run.sh --vfs vfs/deep.zip --script scripts/test_all.sh
```

## Тестирование

Тесты проекта находятся в каталоге `tests`.

Для запуска тестов:

```bash
py -m pytest
```

Тесты проверяют:

- разбор команд и аргументов;
- обработку кавычек;
- раскрытие переменных окружения;
- формирование приглашения командной строки;
- загрузку и работу с VFS из ZIP-архива;
- корректную остановку скрипта при первой ошибке.

## Основные функции

В файле `src/emulator.py` реализованы функции для:

- формирования приглашения командной строки на основе реальных данных ОС;
- разбора введённых команд и аргументов;
- подстановки переменных окружения (`$VAR`, `${VAR}`);
- выполнения команд `ls` и `cd`;
- обработки команды `exit`;
- обработки ошибок (неизвестная команда, неверные аргументы, некорректные кавычки);
- работы со стартовым скриптом с остановкой при первой ошибке;
- обработки параметров командной строки (`--vfs`, `--script`);
- загрузки VFS из ZIP-архива в память;
- представления вложенных элементов VFS.
