# Эмулятор UNIX shell

## Описание

Проект представляет собой эмулятор командной оболочки UNIX,
реализованный на языке Python.

На текущем этапе реализованы первый и второй этапы задания:

* REPL (Read-Eval-Print Loop);
* настройка параметров запуска через командную строку;
* указание пути к виртуальной файловой системе (VFS);
* указание пути к стартовому скрипту;
* выполнение команд из стартового скрипта;
* обработка ошибок при выполнении скрипта;
* продолжение выполнения скрипта после ошибки;
* продолжение интерактивной работы после завершения скрипта.

* Python 3.8 или выше.

Для запуска тестов требуется `pytest`.

## Этап 1. REPL

После запуска программа отображает приглашение командной строки с
информацией о пользователе, имени компьютера и текущем каталоге:

```text
username@hostname:~$
```

Поддерживаются следующие команды:

* `ls` — заглушка команды просмотра содержимого каталога;
* `cd` — заглушка команды перехода в каталог;
* `exit` — завершение работы эмулятора.

### Команда ls

```text
username@hostname:~$ ls
ls: args = []
```

С аргументами:

```text
username@hostname:~$ ls -l test
ls: args = ['-l', 'test']
```

### Команда cd

```text
username@hostname:~$ cd test
cd: args = ['test']
```

### Неизвестная команда

```text
username@hostname:~$ hello
Ошибка: неизвестная команда: hello
```

### Некорректные кавычки

```text
username@hostname:~$ ls "test
Ошибка: некорректные кавычки в команде.
```

### Выход

```text
username@hostname:~$ exit
Выход из эмулятора.
```

## Этап 2. Конфигурация

Эмулятор поддерживает параметры командной строки для настройки запуска.

Поддерживаются:

* путь к физическому расположению VFS;
* путь к стартовому скрипту.

При запуске эмулятор выводит значения заданных параметров в
отладочном режиме.

Пример:

```bash
py src\emulator.py --vfs C:\path\to\vfs --script C:\path\to\script.txt
```

### Стартовый скрипт

Стартовый скрипт содержит команды эмулятора, которые выполняются
последовательно после запуска программы.

При выполнении скрипта на экране отображаются как введённые команды,
так и их результаты, имитируя обычный диалог пользователя с
эмулятором.

Например, скрипт:

```text
ls
cd test
ls -l
```

выполняется аналогично интерактивному вводу команд:

```text
username@hostname:~$ ls
ls: args = []

username@hostname:~$ cd test
cd: args = ['test']

username@hostname:~$ ls -l
ls: args = ['-l']
```

### Обработка ошибок в скрипте

Если во время выполнения стартового скрипта встречается ошибочная
команда, ошибка выводится сразу, но выполнение скрипта продолжается.

Например:

```text
ls
unknown
cd test
```

Результат:

```text
username@hostname:~$ ls
ls: args = []

username@hostname:~$ unknown
Ошибка: неизвестная команда: unknown

username@hostname:~$ cd test
cd: args = ['test']

Где то в вашем скрипте ошибка
```

После завершения скрипта эмулятор не прекращает работу. Пользователь
может продолжить вводить команды в интерактивном режиме.

## Переменные окружения

При разборе команд поддерживается подстановка переменных окружения
в формате `$VARIABLE` и `${VARIABLE}`.

Например:

```text
ls $HOME
```

## Тестирование

Тесты проекта находятся в каталоге `tests`.

Для запуска тестов:

```bash
py -m pytest
```

Тесты проверяют разбор команд, аргументов, кавычек и формирование
приглашения командной строки.

## Основные функции

В файле `src/emulator.py` реализованы функции для:

* формирования приглашения командной строки;
* разбора введённых команд и аргументов;
* подстановки переменных окружения;
* выполнения команд `ls` и `cd`;
* обработки команды `exit`;
* обработки ошибок;
* работы со стартовым скриптом;
* обработки параметров командной строки.
